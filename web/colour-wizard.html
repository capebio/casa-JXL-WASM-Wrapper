White Balance Visualizer

Camera RGB scatter · grey locus · white point
Load a RAW file to see the WB scatter diagram.
How to read this chart:
Each dot is a pixel's (R/G, B/G) ratio — the standard camera WB space. A perfectly grey pixel sits at R/G = B/G = 1 (orange circle).

Auto-sampled grid points (transparent) show the overall scene distribution. User-sampled points (solid, coloured) are the patches you clicked in Section 1.

The dashed diagonal is the grey locus. Coloured scenes (sky, foliage) cluster away from this line.

Sign-off Checklist

Golden corpus · PASS/REVIEW badges

Load a golden corpus via ?corpus=./docs/golden-corpus.json. Each entry is compared against the current render. PASS = butteraugli < 0.05 · REVIEW = ≥ 0.05.

Manual approval step
After visually approving all PASS items, run:
node scripts/golden-check.mjs --update
Or via Tauri: invoke('golden_check', {'{'}update: true{'}'})
This updates docs/golden-corpus.json checksums.
